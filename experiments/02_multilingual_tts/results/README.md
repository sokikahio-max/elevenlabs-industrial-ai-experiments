# Results

Running `multilingual_tts_demo.py` creates:

`multilingual_tts_results.csv`

The CSV contains:

```text
language,text,output_file,elapsed_seconds
```

Generated runtime results are excluded from Git so that repeated local
experiments do not create unnecessary commits.

For a publication-oriented evaluation later, selected benchmark results can be
copied into a versioned dataset under a dedicated `data/` or `evaluation/`
folder.
